# «Топ смен» — открывающееся окно

Изменения подготовлены для проекта `KIZNAIVER-HACKATON-2026/hacaton_main` на основе коммита `40157be8975609232ce432f02e37c07d1492b497`.

## Что изменено

- Постоянный блок «Топ смен» справа убран из основной сетки.
- Кнопка **«Рекорды»** в верхнем меню, рядом с личным кабинетом, открывает окно «Топ смен».
- Кнопка «Топ смен» в подвале открывает это же окно.
- Закрытие: крестик, кнопка «Закрыть», Escape или клик по затемнённому фону.
- Сохранены пиксельное оформление, места, очки, даты и выделение первых трёх игроков.
- Фон нельзя прокручивать или активировать, пока окно открыто. Tab и Shift+Tab обходят элементы окна, а после закрытия фокус возвращается на кнопку открытия.
- На небольших экранах прокручивается содержимое окна; кнопки закрытия остаются видимыми.
- Рейтинг обновляется при открытии и раз в минуту, пока окно открыто. При ошибке сети сохраняются уже показанные данные.
- Старые ссылки вида `index.php#top` продолжают открывать рейтинг.

Изменения базы данных и новые зависимости не требуются. Логика игр и личного кабинета не изменялась.

## Установка из ZIP

1. Сделайте резервную копию текущих файлов проекта.
2. Распакуйте архив **в корень проекта**, сохранив пути и согласившись на замену:
   - `index.php`;
   - `assets/css/main.css`.
3. Добавьте новый файл `assets/js/leaderboard.js` (он также находится в архиве).
4. Файл `tests/leaderboard-modal.cjs` нужен только для проверки, для работы сайта он необязателен.
5. Откройте главную страницу и нажмите «Рекорды». При необходимости обновите страницу с очисткой кеша.

ZIP содержит только изменённые/новые файлы, а не весь проект. Не заменяйте им всю папку проекта.

## Альтернатива: применить патч

Если вы скачали отдельный файл `top-shifts-modal.patch`, выполните в корне чистой исходной копии проекта:

```bash
git apply --check /путь/к/top-shifts-modal.patch
git apply /путь/к/top-shifts-modal.patch
```

Выберите один способ: распаковка файлов **или** применение патча. Повторно применять патч после замены файлов не нужно.

## Проверки

Синтаксис всех PHP-файлов проверен через `php -l`, новых JavaScript-файлов — через `node --check`. Пройдено **17 браузерных проверок в Chromium**: открытие и закрытие, клавиатура, блокировка фона, обновление и пустой рейтинг, ошибка API, безопасный вывод ников, ссылка `#top`, мобильная адаптация и совместимость с энциклопедией.

Чтобы повторить браузерные проверки:

```bash
# Терминал 1, из корня проекта:
php -S 0.0.0.0:8080

# Терминал 2, из корня проекта:
npm ci
CHROMIUM_PATH=/usr/bin/chromium node tests/leaderboard-modal.cjs
```

Нужны PHP, Node.js и установленный Chromium/Chrome. В `CHROMIUM_PATH` укажите путь к вашему браузеру; `TEST_BASE_URL` позволяет указать другой адрес PHP-сервера. API рейтинга в тестах подменяется фикстурами; тесты не создают игроков и не записывают результаты в базу.
