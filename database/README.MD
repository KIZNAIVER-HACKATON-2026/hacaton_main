# База данных

- Для чистой установки импортируйте `schema.sql`, затем при необходимости `seed.sql`.
- Для уже развёрнутой базы выполните один раз `migration_2026_progression.sql`: он создаёт таблицу постоянной прогрессии личного кабинета.

После миграции игроки получают нулевой бюджет и XP; их нельзя купить или начислить вручную через браузерный интерфейс. Награды добавляются сервером после уникального завершённого результата.
