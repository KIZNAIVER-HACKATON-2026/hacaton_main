# Звук «Смены 03»

Вся музыка и все эффекты **синтезируются в браузере** (Web Audio API) модулем
`assets/js/sound.js`. Аудиофайлов нет: модуль весит ~45 КБ, работает офлайн и не требует лицензий.
Стиль — тёмный эмбиент (пэды, дождь, гром, пульс монитора) с 8-битной мелодией сверху.

## Музыкальные темы

| Тема | Где звучит | Характер |
|---|---|---|
| `menu` «Вернуться на линию» | главная, правила, вступление эпизода, сцена после смены | ля минор, 70 BPM, тихий дождь, «тук-тук» сердца, 8-битная мелодия; изредка далёкий гром |
| `prologue` | пролог (шторм, вызов №17) | гул, музыкальная шкатулка, помехи в эфире, ливень; гром совпадает со вспышками молнии |
| `shift` | сама смена | ре минор, пульсирующий бас и сигнал монитора. **Ускоряется** (94 → 126 BPM) и уплотняется, когда время кончается |
| `operation` | учебная операция | ми минор, ровный монитор, сосредоточенно |
| `ending` | концовка сезона | до мажор: та же тема, что в меню, но светлая — рассвет после шторма |

## Эффекты

- **Интерфейс:** клик, наведение, подтверждение / назад, вкладки, печать в поле ввода.
- **Голоса персонажей при печати текста** (как в ретро-RPG): у Веры, Ильи, Сони, Громова,
  Петра Андреевича, героя и «неизвестного номера» свой тембр и высота; пролог — пишущая машинка, SMS — тихие щелчки.
- **Смена:** верный / неверный диагноз, шаги лечения (каждый следующий выше), «пациент спасён»,
  вызов диспетчера (рация), сюжетный вызов с помехами, решение в истории, тики последних 10 секунд,
  сигнал «осталась минута», пауза, итог смены (успех / провал).
- **Сюжет:** карточка эпизода, вибрация и SMS, дверца «Шкафчика №12», новая улика, гром.
- **Операция:** взять инструмент, приложить к пациенту, ошибка, вернуть на стол.
- **Кабинет:** покупка (монетка) / ошибка.

Во время диалогов музыка приглушается, на паузе — ещё сильнее.

## Управление

Кнопка с динамиком в шапке (главная, правила, операция) и в HUD смены: громкость музыки и
эффектов, «Выключить звук». Клавиша **M** — включить / выключить. Настройки хранятся в
`localStorage` (`shift03-sound-v1`).

Браузеры разрешают звук только после действия пользователя. Поэтому новый гость перед прологом видит
заставку «▶ Начать со звуком / Без звука». В остальных случаях тема стартует с первого клика.

## API (для разработчиков)

```js
SFX.play('correct');               // эффект
SFX.voice('vera', 'а');            // «голос» при печати символа
SFX.music('menu');                 // сменить тему (плавный кроссфейд); null — тишина
SFX.pushMusic('prologue'); SFX.popMusic();
SFX.intensity(0.8);                // напряжение темы смены 0..1
SFX.duck('pause', 0.3); SFX.unduck('pause');
```

Новая тема — это объект в `TRACKS` с `bpm`, `bars` и функцией `step()`, которая на каждом
шестнадцатом шаге решает, какие ноты сыграть. Новый эффект — функция в `FX`.
