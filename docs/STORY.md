# Сюжет «Вернуться на линию» (сезон 1)

Фельдшер возвращается на подстанцию 03 через два года после тяжёлого вызова №17,
после которого он ушёл из профессии. Шесть смен — шесть эпизодов: герой
разбирается, что случилось в ту ночь, и решает, остаться ли ему на линии.

## Как устроено

| Где | Что |
|---|---|
| `includes/story_episodes.php` | Все тексты: пролог, 6 эпизодов, 3 концовки. Редактируется без программиста. |
| `includes/story.php` | Прогресс игрока (таблица `player_story`, создаётся автоматически), правила продвижения, выбор концовки. |
| `api/story.php` | `GET` — состояние, `POST complete` — завершить эпизод, `POST reset` — начать сезон заново. |
| `assets/js/story-line.js` | Общий модуль: текущий эпизод, фильтр реплик по флагам, пролог, карточка эпизода, SMS, концовка. |
| `assets/js/shift.js` | Встраивание эпизода в смену: вступление → сюжетный звонок посреди смены → сцена после смены → SMS → (финал) концовка. |
| `assets/js/story-landing.js` | Главный экран как начало истории: автозапуск пролога для нового гостя, вход «Кто на линии?», кнопка «Шкафчик №12». |
| `assets/js/cabinet.js` | Реплики персонажей на покупки (рация → Вера, больница → Илья, первое оборудование → Соня). |
| `assets/js/story-dialogue.js` | Новые персонажи: Соня, Громов, Пётр Андреевич, герой, «неизвестный номер». |
| `assets/css/story-line.css` | Стили всех сюжетных элементов. |

## История с первого экрана

Отдельной вкладки «История» нет — сюжет встроен в саму игру:

1. **Первый визит.** Новый гость открывает главную — сразу проигрывается пролог (шторм,
   вызов №17). Затем Вера спрашивает: «Смена 03, проверка связи… Кто на линии?» — игрок
   вводит ник и **сразу попадает в первую смену** (эпизод 1). Пролог показывается один раз
   (`localStorage: shift03-prologue-seen-v1`), дальше его можно пересмотреть в шкафчике.
2. **Главное меню** рассказывает, где игрок в истории: название сезона, тизер текущего
   эпизода, полоса из 6 эпизодов, кнопка «Начать историю» / «Следующая смена», последнее
   SMS (от неизвестного номера — дрожит).
3. **«Шкафчик №12»** — внутриигровой журнал героя (оверлей): «Журнал» (эпизоды и повтор
   сцен), «Улики» (доска), «Телефон» (SMS), «Пролог», концовка и «Начать сезон заново».
   Открывается из главного меню, по SMS-виджету, из HUD смены (кнопка «Эп. N/6 · название»,
   таймер смены на это время стоит) и из финального блока смены.
4. **Кабинет** — покупки сопровождаются репликами персонажей.
5. Новый игрок, вошедший через форму в кабинете, тоже сразу отправляется в смену.

## Правила

- **Одна смена = один эпизод.** Эпизод засчитывается после любой завершённой смены —
  даже провальной или с нулём очков: история не застревает. После провала показывается
  другая сцена (`after.fail`).
- **Сюжетный звонок** приходит после 3-го пациента. Выбор меняет «доверие команде» и
  «доверие себе», ставит флаги, от которых зависят реплики в следующих эпизодах.
  Эффекты выбора сервер берёт из своих данных по номеру варианта — подделать нельзя.
- **Концовки:** «На линии» (доверие команде ≥ 4), «Свой путь» (доверие себе ≥ 2),
  иначе «Ещё одна смена».
- Если в кабинете куплена **радиостанция**, в финале появляется дополнительная реплика Веры.
- В эпизоде 3 после учебной операции показывается отдельная сцена с Ильёй.
- Если БД недоступна, прогресс истории хранится в localStorage браузера.

## Для показа жюри

`game.php?episode=N` (N = 1…6) — демо любого эпизода. Прогресс истории и автосейв
в демо не записываются. Например, `game.php?episode=6` — финал со штормом и звонком
Петра Андреевича. Начать сезон заново: главная → «Шкафчик №12» → «Начать сезон заново»
(кнопка появляется после финала) или `POST api/story.php {action:"reset"}`.

## Установка поверх существующего проекта

1. Скопировать файлы поверх проекта.
2. Миграция не обязательна: таблица `player_story` создастся сама. Для ручной установки —
   `database/migration_2026_story.sql`.
3. Обновить страницу с очисткой кэша (Ctrl+F5).
